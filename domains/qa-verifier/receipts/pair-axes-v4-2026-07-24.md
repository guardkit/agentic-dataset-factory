## The catch of record — a green suite masking a real defect

The adversarial coach broke round 1: `_claimed_passing` gated counts on `isinstance(v, int)`,
and **Python's `bool` subclasses `int`** — real gather emits `quality_gates.tests_passed: true`
(a bool flag, never a count) with no `tests_passing` key, so on every real spine the claimed
count became `True`(1): bools leaked into `independent_tests.collected`, loci rendered "the
same True tests passing", counts went internally inconsistent (skipped=2 of collected=1), and
the skip ranges collapsed to constants — **minting a `skipped==2 ⇒ reject / ==1 ⇒ approve`
shortcut, the exact shape→class disease this program exists to cure.** The 2778-test suite was
green because BOTH fixtures injected a synthetic int `tests_passing` that production never
emits. The bridge spike independently confirmed (axis-D NO-GO) while passing the api_test
vacancy pair end-to-end, the forge b2 variant (jarvis-receipt bar), and the shingle law.

**The fix (coordinator-verified after the fixer's reporting channel failed):** `_int_count`
with load-bearing `not isinstance(v, bool)`; claimed derived from genuine int counts through
quality_gates → tests → independent_tests with the varied 4..12 fallback; in-construction
junit-consistency asserts; fixtures rewritten gather-faithful (bool flags, no synthetic
count key) + an int-shape variant + regression tests. Suite **2796 passed, exit 0**.
